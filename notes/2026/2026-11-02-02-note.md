# 中国地图少一块，先看底图

> 2026-11-02 · 日常技术记录

渲染出来的中国地图，台湾、香港、澳门都有颜色，南海方向空白、没有十段线。这通常不是代码画错了，是底图里根本没有那个 feature。

内置的简化底图往往只有三十来个行政区，南海诸岛不在其中。判断方法很直接：数一遍 feature 的名字，看到没有南海诸岛就是中招。

换完整底图之后有两个坑。一是十段线那个 feature 的 name 是空串，入库前要补上名字，否则按名字匹配和图例里都是哑的；二是完整底图的中心点字段名和简化底图不一样，取中心的代码要有几何质心的回退，不然航线端点全部匹配失败。

验收别看命令行输出，直接截图确认台湾、香港、澳门、南海诸岛四处真的画在画布上。

世界底图另说。它通常没有单独的台港澳 feature，因为包含在中国多边形里，属于正常形态，不要去改。
